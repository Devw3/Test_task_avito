# Avito Bootcamp
## Задача
По событиям `cookie_id` за суточное окно предсказать вероятность того, что трафик относится к автоматизированному сборщику данных.

## Решение
- Нормализация `platform` → `web / android / ios`.
- Удаление дубликатов и событий вне окна наблюдения для предотвращения leakage.
- Восстановление пропусков по `item_id`.
- Сбор 60 поведенческих признаков: паузы, курсор, объём и разнообразие активности, поиск, funnel, UA и признаки cookie.
- Валидация по временным окнам.
- Сравнение разных моделей; лучшими и наиболее стабильными оказались бустинги.
- Финальный ансамбль `CatBoost + XGBoost + LightGBM` с усреднением рангов предсказаний.

## Тестирование
Для проверки использовалась **временная валидация**: модель обучалась на более ранних временных окнах и тестировалась на следующих. Такой подход имитирует реальное предсказание будущего трафика и предотвращает утечку информации из будущего. Качество оценивалось по основной метрике задачи **Precision при Recall ≥ 70%**, а также по PR-AUC и ROC-AUC для дополнительной диагностики.

## Результат
Финальный файл содержит:
- `cookie_id` — идентификатор cookie;
- `score` — оценка вероятности бота от 0 до 1.

На out-of-time validation ансамбль получил `P@R≥70% = 0.777`, `PR-AUC = 0.789`, `ROC-AUC = 0.940`.

## Запуск
Основной код находится в `avito-test-task.ipynb`. Для воспроизведения необходимо установить зависимости из `requirements.txt` и выполнить ноутбук.
